# 📸 WallpaperApp (React Native)

WallpaperApp is a modern image discovery application powered by the Pixabay API.
It allows users to browse images by category, refine results using advanced filters, and search through millions of photos with a clean, smooth, and intuitive UI.

The app features rich animations, responsive design, and a highly interactive interface built with modern React Native tooling.


## 🚀 Features

- 🔍 **Smart Search:**  
  Search through millions of high-quality images using any keyword.

- 🗂️ **Category Browsing:**  
  Quickly explore images by selecting one of the predefined categories.

- ⚡ **Smooth Animations (Reanimated):**  
  Built with Reanimated, the user experience has become lively, fluid and premium.

- ❤️ **Interactive Bottom Sheet:**  
  Used for filters, details, and additional UI interactions with modern gesture support.
  
- 🌐 **Pixabay API Integration:**  
  Fast and scalable data fetching via Axios.

- 📱 **Fully Responsive Layout:**  
  A custom scaling system:

  · horizontalScale

  · verticalScale

  · scaleFontSize

  ensures consistent designs across all screen sizes.
  
- 🎨 **Modern UI Design:**  
   · Beautiful icon set (FontAwesomeIcon)
   · BlurView modals
   · Soft shadows & overlays
   · Minimal, modern theme
